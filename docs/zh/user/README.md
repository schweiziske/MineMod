按住默认的 `C` 键，在上下文菜单左上角点击 **MC Config** 打开设置。
也可在 GMod 控制台输入以下命令打开对应界面：

| 命令 | 界面 |
|---|---|
| `mc_config` | 设置 |
| `mc_save_manager` | 存档管理器 |
| `mc_preset_manager` | 预设管理器 |
| `mc_texture_packs` | 材质包管理器 |

材质包和光影包影响自己的画面；建造、读档和服务器规则影响服务器中的世界。
多人游戏的存档在服务器上，单人游戏则在本机。
