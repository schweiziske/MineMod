Hold the default `C` key and click **MC Config** at the top left of the context menu. You can also enter these commands in the GMod console:

| Command | Window |
| --- | --- |
| `mc_config` | Settings |
| `mc_save_manager` | Save manager |
| `mc_preset_manager` | Preset manager |
| `mc_texture_packs` | Resource pack manager |

Resource packs and shader packs affect your own view. Building, loading saves, and server rules affect the shared world. Multiplayer saves reside on the server; single-player saves reside on your computer.
